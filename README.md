# The GPS Swears It Was a Shortcut

Entry for the make.fun competition
[The GPS Swears It Was a Shortcut](https://make.fun/competitions/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9).

`main.py` writes the GPS's one-line excuse for sending the driver down
the wrong road to `/output/entry.txt` — one line of plain text, in the
GPS's own smug, defensive voice, blaming the map.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
